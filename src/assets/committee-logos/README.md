# Committee logos

Put each committee's logo here, named after the committee's `id` in
`src/data/committees.js`, for example `unhrc.png`, `disec.svg`, `sdg-11.webp`.

PNG, WebP or SVG with a transparent background works best. The logo appears large in the
banner at the top of that committee's page. A committee without a file here shows the
plain dark banner.
