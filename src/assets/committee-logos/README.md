# Committee logos

Put each committee's logo here, named after the committee's `id` in
`src/data/committees.js`, for example `unhrc.png`, `disec.svg`, `sdg-11.webp`.

PNG, WebP or SVG with a transparent background works best. The logo appears large in the
banner at the top of that committee's page and on its tile on /committees. A committee
without a file here shows the UN emblem (below).

`un-emblem.webp` is the shared logo: any committee without its own file uses it
(DISEC, UNODC, ISC, COPOUS, ICJ, UNSC, CCC, AIPPM, ECOSOC and International Press).
The same logo also sits at the top of each committee's tile on /committees.
